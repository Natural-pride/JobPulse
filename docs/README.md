## 文档约定

- 全部用中文写（除根目录 3 个 GitHub 自动识别的文件名外）
- Markdown，GitHub 直接渲染
- Mermaid 图用于 ER 图 / 流程图
- 代码示例真实可跑（curl / JSON / SQL）

## 文档怎么改

文档跟代码一起改：

- 改 schema → 同步改 [数据模型](./数据模型.md)
- 改 / 新增 API 端点 → 同步改 [API](./API.md)
- 改模块结构 → 同步改 [架构](./架构.md)
- 改开发流程（命令、目录） → 同步改 [开发](./开发.md)
- 改路线 / 计划 → 同步改 [路线图](./路线图.md)

PR 里可以同时改代码和文档，commit message 写清楚"为什么"。
